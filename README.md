# 원장님 MVP

1인 교습소와 공부방 운영자가 협업을 요청하고, 지원 검토와 요청 원장의 선택을 거쳐 매칭별 후속 업무를 관리하는 반응형 웹서비스의 v0 시연 앱입니다.

## 실행

```zsh
npm install
npm run dev
```

화면의 `DEMO MODE`에서 회원 또는 관리자 시연 계정을 선택합니다. 로그인 정보는 요구하지 않습니다.

## v0 기능

- 협업 요청 목록, 검색, 분류 필터와 상세 화면
- 샘플 데이터를 이용한 협업 요청 작성과 지원
- 회원의 요청·지원 관리 및 요청 원장의 수락·거절 시연
- 관리자 검토 대기열과 지원 승인·종료 시연
- 매칭별 진행 단계, 다음 할 일, 활동 메모 관리
- 데스크톱과 모바일 화면을 위한 반응형 UI

화면 입력과 변경은 브라우저 메모리에서만 유지되며 새로고침하면 샘플 상태로 초기화됩니다. 실제 인증, 데이터베이스, 결제 및 개인정보 처리는 구현하거나 연결하지 않았습니다. 연락처 공유도 시연 환경에서 사용할 수 없습니다.

## 화면 및 디자인 구성

화면은 PRD의 S-01~S-15와 권장 경로를 기준으로 구성했습니다. Figma 화면을 구현할 때 참고할 수 있도록 재사용 UI는 `src/components/`, 화면은 `src/pages/`, 시각 토큰과 반응형 규칙은 `src/styles.css`에 분리했습니다.

## 개발 도구

React, TypeScript, Vite, React Router, Lucide, VS Code, Claude Code를 사용합니다. Supabase는 이 v0 데모에서 연결하지 않습니다.
