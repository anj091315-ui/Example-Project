# Acceptance Criteria 체크리스트

`docs/PRD.md`의 `10. Acceptance Criteria`에 정의된 검증 조건을 추적하기 위한 문서입니다. 체크 표시는 실제 구현과 검증 결과를 확인한 뒤 갱신합니다.

## AC-01. 인증

- [ ] 학생이 정상적으로 회원가입할 수 있다.
- [ ] 유효한 계정으로 로그인할 수 있다.
- [ ] 잘못된 로그인 정보 입력 시 오류 메시지가 표시된다.
- [ ] 로그아웃 시 세션이 종료된다.
- [ ] 일반 회원가입으로 관리자 계정을 생성할 수 없다.

## AC-02. 강의 참여

- [ ] 관리자가 강의를 생성할 수 있다.
- [ ] 강의 생성 시 고유 수업 코드가 자동 생성된다.
- [ ] 학생이 유효한 수업 코드로 강의에 참여할 수 있다.
- [ ] 잘못된 코드 입력 시 오류 메시지가 표시된다.
- [ ] 강의 참여 후 다시 로그인해도 참여 정보가 유지된다.
- [ ] 한 학생이 두 개 이상의 강의에 참여할 수 없도록 제한된다.

## AC-03. 게시글

- [ ] 학생이 질문 및 자유토론 글을 작성할 수 있다.
- [ ] 학생이 공지사항을 작성할 수 없다.
- [ ] 관리자가 공지사항을 작성할 수 있다.
- [ ] 게시글 목록이 최신순으로 표시된다.
- [ ] 카테고리별 필터링이 정상적으로 동작한다.
- [ ] 게시글 상세 페이지에서 제목, 본문, 작성자, 조회수가 표시된다.
- [ ] 본인이 작성한 글을 수정하거나 삭제할 수 있다.
- [ ] 다른 학생의 게시글을 수정하거나 삭제할 수 없다.
- [ ] 관리자가 자신이 관리하는 강의의 게시글을 삭제할 수 있다.
- [ ] 게시글 상세 페이지 진입 시 조회수가 증가한다.

## AC-04. 댓글

- [ ] 게시글에 댓글을 작성할 수 있다.
- [ ] 댓글 작성 후 새로고침해도 내용이 유지된다.
- [ ] 본인이 작성한 댓글을 수정하거나 삭제할 수 있다.
- [ ] 다른 학생의 댓글을 수정하거나 삭제할 수 없다.
- [ ] 관리자가 자신이 관리하는 강의의 댓글을 삭제할 수 있다.

## AC-05. 접근 권한

- [ ] 비로그인 사용자는 강의 커뮤니티에 접근할 수 없다.
- [ ] 학생 계정으로 관리자 페이지에 접근할 수 없다.
- [ ] 학생은 참여하지 않은 강의의 게시글과 댓글을 조회할 수 없다.
- [ ] URL을 직접 입력하거나 API 요청을 조작해도 접근 권한을 우회할 수 없다.
- [ ] 관리자는 다른 관리자가 소유한 강의 데이터를 임의로 변경할 수 없다.

## AC-06. UI/UX

- [ ] 주요 페이지가 데스크톱에서 정상적으로 표시된다.
- [ ] 모바일 화면에서도 주요 기능을 사용할 수 있다.
- [ ] 로딩 상태 및 오류 메시지가 정상적으로 표시된다.
- [ ] 게시글 작성부터 강사 답변 확인까지 핵심 시나리오가 정상적으로 동작한다.
